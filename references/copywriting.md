# 文案：句式、降维、改写

## 一、字数与排版

来自 425 篇热门笔记的统计：正文长度中位 **91 字**，但热度是**两头高、中间塌**——

| 字数 | 中位赞 |
| --- | --- |
| ≤50 | 6286 |
| 50–100 | 3458 |
| 100–200 | 3114 |
| 200–400 | 122 |
| 400+ | 6490 |

所以只有三种写法：

- **≤50 字 一句流**：封面和标题已经把事说完，正文只补一句现场/情绪。
- **50–120 字 三行说明**：结论 → 2–3 个具体细节 → 一句人话。
- **400+ 字 长文**：亲身经历、深度测评，靠"我看完了"换收藏。

**永远不要写 200–300 字**：想讲清楚又讲不透，读者既没被逗笑也没被说服。

排版：

- 首行 40 字内说完最有用的一句（手机上正文只显示 2 行）
- 每段 ≤4 行，段间空一行（样本 41.4% 含换行）
- 少用逗号连句，多用句号断开
- Emoji 全篇 ≤3 个，只当分隔符（样本含 emoji 仅 13.8%）
- 标签 5–8 个，末尾内联 `#话题#`

## 二、真人感：先给反应，再给事实

判断标准只有一条：**这段话像不像一个真人在跟朋友讲话。**

三个标志：

- **有反应**：第一句是"人"的反应，不是"事"的结论。"我连看了三遍""我宣布""我看愣了"——情绪在前，事实在后。
- **有立场**：敢说"我站谁""值不值"。没有立场的文案，读起来像通稿。
- **有具体动作**：连看三遍、倒回去又看一遍、截图发给朋友。抽象形容词（"效果显著""表现优异"）一律换成动作。

允许适度夸张，但夸张必须对得上事实：

| 可以 | 不可以 |
| --- | --- |
| 差了一条街 / 有点离谱 / 贵得有理 | 一个做出了游戏（当它只是一段视频） |
| 我宣布，新神归位 | 行业格局已被改写（假大空） |

**删掉这些总结腔**：一眼看出、肉眼可见、差距明显、可以看出、本质上是、值得一提、这启示我们。

### 情绪要站队，不要"看起来很客观"

- **好就是好，差就是差。** 判断句比分析句有力。
- **不洗地**：不写"客观说""各有各的好""可能是风格差异""也不能说它不行"。
- **不下专业结论**：我们看不出模型内部的能力差异，硬解释只会露怯，读者也拿不到价值。

| 洗地 | 直接说 |
| --- | --- |
| DeepSeek 也有它的优点，只是这次风格不太一样 | 这局就是被按在地上摩擦 |
| 可能是提示词碰巧更契合 Opus | 同一个提示词，差距就这么赤裸 |

### 不解释画面，只给情绪判断

**画面细节基本不写。** 看图这件事上读者不比我们差，解释细节等于把短板交出去，而且这些解释对读者没有价值。

| 别写（解释画面） | 写成（给判断） |
| --- | --- |
| 不是它不会画像素风，是它画出来的东西不太"发生" | 这局就是被按在地上摩擦 |
| 它的构图缺少前景层次，光影也更平 | 看完只想说一句：辛苦你了 |
| 角色移动幅度明显更大 | 一句话出片，商业级 |

**唯一可以展开的是画面里的文字**：对话框、标题、界面文案——那是所有人都能对上号的硬信息。

### 三类核心需求

读者点进来，图的是这三件事，文案至少要踩中一个：

| 需求 | 对应写法 |
| --- | --- |
| 省事 | 动动手指、一句话、不用自己抠三天 |
| 焦虑 | 别人已经用上了、再不会就落后了 |
| 情绪价值 | 解气、好笑、看得爽 |

### 真人四段骨架

| 段 | 行数 | 作用 | 写法 |
| --- | --- | --- | --- |
| 反应 | 1 | 一句情绪开场 | 第一人称 + 惊叹/站队/吐槽 |
| 事实 | 3–4 | 一句话说清比了什么、结果如何 | 只写能核对的东西（谁的、多少、有没有） |
| 差距 | 1–2 | 一句能截图的结论 | 口语、下判断，不解释为什么 |
| 收尾 | 1 | 立场或吐槽 | "这钱我认""谁还自己抠帧" |

### 示例（166 字，AI 视频对比）

> 同一个提示词，我让它俩各生成一段像素风动画。
>
> Opus5.5 一句话，直接给我一整段能用的：场景、角色、镜头，连中文对话框「欢迎来到像素世界！」都齐了。
>
> DeepSeek 那版，我看完只想说一句：辛苦你了。
>
> 不开玩笑，这局就是按在地上摩擦，没什么可辩的。
>
> 贵十几倍，但这是商业级出片，我认。
>
> 以后谁还自己抠像素帧？动动手指的事，省下来的时间够刷十集剧 🙃

拆解：

- 反应：`一句话，直接给我一整段能用的`
- 事实：能核对的部分——同一句提示词、中文对话框、一整段
- 差距：`按在地上摩擦`——下判断，不解释
- 收尾：`谁还自己抠像素帧`——踩中"省事"

## 三、术语降维对照表

| 原表述 | 降维后 |
| --- | --- |
| 高危 RCE 漏洞 | 爆了个严重漏洞 |
| 未经授权的远程代码执行 | 谁都能进你的服务器 |
| PoC 已公开传播 | 黑客攻击代码满天飞 |
| 临时关停站点 | 连夜把网线拔了 |
| 应急响应 | 连夜处理 |
| 供应链攻击 | 上游被人动了手脚 |
| 零日漏洞 | 补丁还没出就被人打了 |
| 数据泄露 | 用户信息被人拖走了 |

原则：**翻译成"人在现场会做的动作"，不是翻译成更简单的术语。**

## 四、词汇黑名单

出现即删：

| 类别 | 禁用词 |
| --- | --- |
| 机械拉关系 | 家人们、姐妹们、谁懂啊、绝绝子、一整个住了、狠狠共情 |
| 通稿腔 | 据悉、值得一提的是、综上所述、不难发现 |
| 震惊体 | 震惊！、居然……竟……、看完我沉默了 |
| 说教腔 | 我们应该认识到、这启示我们 |

这些词会让读者立刻识别出"这是营销号"，然后划走。

## 六、标题写法

- 15 字上下（宁可短，别硬凑）
- 必须含 1–2 个搜索关键词（模型名、产品名、事件名）
- 带情绪或站队，不要写成一句总结

四种可用结构：

| 结构 | 例 |
| --- | --- |
| 人物 + 冲突 | 高市早苗官网，被PHP干停了 |
| 反差 + 悬念 | 写防黑客书的首相，被PHP干碎了 |
| 具体细节前置 | 出版社叫PHP，官网也被PHP干停 |
| 第一人称 + 站队 | 我宣布，AI视频新神是Opus5.5 |
| 惊叹 + 结论 | 吓哭了，Opus5.5一句话出商业级像素动画 |
| 惊叹 + 代价 | Opus5.5 这视频，贵得有理 |

不要用：总结句（"AI做的像素游戏，一眼看出贵在哪"）、纯陈述（"XX官网暂时关闭"）、震惊体、疑问句套话（"你知道XX吗"）。

**总结句为什么不行**：它把结论先摆出来，读者没有"我也有同感"的入口；而且一听就是通稿，不像人说的话。

## 七、标签

5–7 个，结构：

- 2 个大流量词（#网络安全 #程序员）
- 3 个精准搜索词（#高市早苗 #PHP #漏洞）
- 1–2 个情绪词（#离谱 #地狱笑话）

大流量词决定推荐池，精准词决定搜索命中，情绪词决定互动意愿。

---

## 八、默认不写首评

**交付只有标题 + 正文。** 不写置顶首评、不写"补点硬料"、不写发布设置。

用户明确要看评论时，才补一条，格式仍然是三段以内、有编号、有出处，但**不写原博主和原帖链接**：

```
补点硬料：

- 9/22 发布，API 输入 $4 / 输出 $20（每百万 token）
- 对面 9/10 发布，10/17 又更了一版，输出高峰 8 元、空闲 4 元
- 按输出价算，差十几倍
```

技术细节可以进评论，但不能把"我从哪转的"写进去。

---

## 九、不提原帖

正文和图里都不出现这些词：原帖、原博主、博主说、转发、搬运、"看到一条"。

**为什么删：** 一提来源，帖子就从"我说的一件事"降级成"我转述的一件事"，读者对内容的信任度和你的作者感同时下降。

| 干 | 湿 |
| --- | --- |
| 发帖的博主说，DS 的光影有明显瑕疵 | Opus 这版，中文对话框直接弹出来了 |
| 原帖里博主做了两段对比视频 | 同一句提示词，两个模型各做了一段 |
| 转自 X 上一位网友的测试 | （不提，直接讲结果） |

**唯一的例外**：发帖平台或博主本身就是话题——当事人亲自发的、官方账号下场的、大 V 本人就是新闻的，可以点名。

## 十、预留槽点

目的：让懂行的人有东西可补，把互动从"求赞"变成"纠错/补充"。

**留缺口，不留错误：**

| 做法 | 结果 |
| --- | --- |
| 只写"严重漏洞"，不给编号 | 懂的人来补 CVE ✅ |
| 写"大概是最严重的漏洞之一" | 有人来纠正范围 ✅ |
| 把 2026 写成 2025 | 被当造谣 ❌ |
| 编一个不存在的编号 | 账号信誉受损 ❌ |

区别在于：缺口是"我没说全"，错误是"我说错了"。
