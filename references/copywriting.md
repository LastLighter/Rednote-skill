# 文案：句式、降维、改写

## 一、字数与排版

- 正文 **150–220 字**，硬上限 300
- 每段 1–3 行
- 大量换行，句子之间留白
- 少用逗号连句，多用句号断开
- Emoji 全篇 ≤ 3 个

字数不是越少越好。150 字以下会显得"没料"，300 字以上没人读完。**180 字左右是最稳的区间。**

---

## 二、四段式骨架

| 段 | 行数 | 作用 | 写法 |
| --- | --- | --- | --- |
| 爆点 | 1–2 | 一句话点明发生了什么 | 主语 + 动作 + 结果，带情绪 |
| 事实 | 3–4 | 交代背景与冲突 | 时间、动作、结果，全用短句 |
| 反转 | 2–3 | 放出最爆的细节 | 对比或递进，最好有一句能截图 |
| 吐槽 | 1 | 冷幽默收束 | 轻描淡写，不加感叹号 |

### 示例（177 字）

> 高市早苗这波，属实把节目效果拉满了。
>
> 她自己的官网，上周连夜下线了。一门叫 PHP 的编程语言爆了严重漏洞，黑客攻击代码满天飞，事务所当晚就把网线拔了，第二天上午才敢重开。
>
> 本来是个常规安全事件。
>
> 结果有人翻出她 2018 年出过一本网络安全漫画书，专门教人怎么防黑客。
> 而这本的出版社，叫 PHP 研究所。
>
> 一个叫 PHP 的出版社，出了防黑客的书。
> 八年后，一个叫 PHP 的语言，把高市早苗的官网干停了。
>
> 这剧本，编剧都不敢这么写 👀

拆解：

- 爆点：`高市早苗这波，属实把节目效果拉满了。`
- 事实：官网下线 → 原因 → 拔网线 → 重开
- 反转：出版社也叫 PHP（这是全文唯一的"点"）
- 吐槽：`这剧本，编剧都不敢这么写`

## 三、术语降维对照表

| 原表述 | 降维后 |
| --- | --- |
| 高危 RCE 漏洞 | 爆了个严重漏洞 |
| 未经授权的远程代码执行 | 谁都能进你的服务器 |
| PoC 已公开传播 | 黑客攻击代码满天飞 |
| 临时关停站点 | 连夜把网线拔了 |
| 应急响应 | 连夜处理 |
| 供应链攻击 | 上游被人动了手脚 |
| 零日漏洞 | 补丁还没出就被人打了 |
| 数据泄露 | 用户信息被人拖走了 |

原则：**翻译成"人在现场会做的动作"，不是翻译成更简单的术语。**

## 四、词汇黑名单

出现即删：

| 类别 | 禁用词 |
| --- | --- |
| 机械拉关系 | 家人们、姐妹们、谁懂啊、绝绝子、一整个住了、狠狠共情 |
| 通稿腔 | 据悉、值得一提的是、综上所述、不难发现 |
| 震惊体 | 震惊！、居然……竟……、看完我沉默了 |
| 说教腔 | 我们应该认识到、这启示我们 |

这些词会让读者立刻识别出"这是营销号"，然后划走。

## 六、标题写法

- ≤ 15 字
- 含 1–2 个搜索关键词
- 有信息缺口

三种可用结构：

| 结构 | 例 |
| --- | --- |
| 人物 + 冲突 | 高市早苗官网，被PHP干停了 |
| 反差 + 悬念 | 写防黑客书的首相，被PHP干碎了 |
| 具体细节前置 | 出版社叫PHP，官网也被PHP干停 |

不要用：纯陈述（"XX官网暂时关闭"）、震惊体、疑问句套话（"你知道XX吗"）。

---

## 七、标签

5–7 个，结构：

- 2 个大流量词（#网络安全 #程序员）
- 3 个精准搜索词（#高市早苗 #PHP #漏洞）
- 1–2 个情绪词（#离谱 #地狱笑话）

大流量词决定推荐池，精准词决定搜索命中，情绪词决定互动意愿。

## 八、置顶首评

正文里删掉的东西，全放这里：

```
补点硬料，正文塞不下：

- 漏洞编号 CVE-XXXX-XXXXX，在核心层，WordPress、Drupal、Laravel 全在射程内
- 10/21 官方披露，当晚官网下线，22 号上午才恢复
- 官方机构 10/22 已发风险提示
- 完整时间线和出处：<来源>

书名《XXX》，2018-12 出版，ISBN XXX
```

格式：三段以内、有编号、有出处。读者扫一眼就知道"这号靠谱"。

---

## 九、预留槽点

目的：让懂行的人有东西可补，把互动从"求赞"变成"纠错/补充"。

**留缺口，不留错误：**

| 做法 | 结果 |
| --- | --- |
| 只写"严重漏洞"，不给编号 | 懂的人来补 CVE ✅ |
| 写"大概是最严重的漏洞之一" | 有人来纠正范围 ✅ |
| 把 2026 写成 2025 | 被当造谣 ❌ |
| 编一个不存在的编号 | 账号信誉受损 ❌ |

区别在于：缺口是"我没说全"，错误是"我说错了"。
