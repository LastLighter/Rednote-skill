## 0. 先认清一件事：你写的不是文章，是"首屏三秒 + 评论区"

小红书的流量结构决定了三件事，写之前必须记住：

1. **推荐流是唯一入口。** 用户看到的是信息流里一个 3:4 的封面 + 两行标题。封面负责"停手"，标题负责"点进去"，正文负责"看完/收藏"，评论区负责"我也想说两句"，最后这四个动作一起决定它推不推给下一批人。
2. **正文在手机上最多显示 2 行**（约 40 字），点开后才展开。所以**首行就是第二个标题**，别把最重要的话放在第三段。
3. **评论不是附属品，是内容的一部分。** 样本里前 5 条评论有 **8% 是作者本人在说话**，其中 **24/133 篇的第 1 条评论就是作者自己**。头部作者把评论区当第二现场在运营。

由此得出写作优先级：**封面 > 标题 > 首行 > 评论钩子 > 正文中后段**。多数人反过来做，所以写得很辛苦但没人点。

## 1. 标题：15 个字，说一件"具体到能想象出画面"的事

### 1.1 数据画像（359 篇）

| 指标 | 数值 |
|---|---|
| 长度中位数 | **15 字**（p25 = 11，p75 = 20，p90 = 25） |
| 含数字 | 13.8% |
| 含 emoji | 12.4% |
| 含感叹号 | 13.3% |
| 含问号 | 8.6% |
| 含引号/括号 | 2.2% / 1.1% |
| 含"我" | 13.3%（多为"我妈…""我以为…"式，纯自我陈述少见） |

**标题长度与热度（中位点赞）：**

| 字数 | 篇数 | 中位赞 |
|---|---|---|
| ≤8 | 38 | 659 |
| 8–12 | 66 | 3458 |
| **12–16** | 88 | **6134** |
| 16–22 | 110 | 2724 |
| 22–30 | 30 | 1551 |
| 30+ | 30 | 6434（长句式，多为新闻/故事搬运） |

**结论：12–16 字是甜点区。** 少于 8 字（如"不费力穿搭"）在垂类里成立，但在泛推荐流里几乎拿不到量——因为信息量不够，用户不知道该期待什么。超过 22 字开始下滑。

> 注意：这是相关性不是因果。12–16 字区间里本来就集中了"能一句话讲清冲突"的内容。

### 1.2 七个真实存在的标题母题

从样本里归纳，爆款标题基本落在下面七类，占比来自规则分类（有重叠）：

**① 陈述一件反常的事（60.7% 归在"纯陈述/其它"，其中大多数是这一类）**
把一件"不合常理但真实发生"的事平铺直叙，不加评价，靠事实本身的荒诞感抓人。

- 女子用虹吸法排积水
- 奶奶把钥匙挂在狗脖子上，画指示牌"仅限家人拿取"
- 我妈也算是吃上相亲的苦了

**② 悬念/提问（19.5%）**
留一个必须点开才能解答的口子。典型是"怎么办""为什么""是不是"。

- 隔壁好像臭了怎么办（后续已更新）
- 为什么总感觉越精神不正常的人反而越有性张力呢？

**③ 教程/干货（8.1%）**
以"怎么做"为承诺，常带数字与限定词。

- 3 款平价连衣裙，显瘦不显肚子
- 夏天一初秋不可少的针织开衫分享（上期）

**④ 极简短语（7.2%）**
4–8 字，靠审美与身份认同筛选人群。垂类账号常用，泛流量账号慎用。

- 不费力穿搭 / 翡翠拼豆 / 首尔三天

**⑤ 情绪爆点（5.3%）**
纯情绪词 + 标点堆叠，几乎不含信息，赌的是"我也这样想"。

- 翡翠拼豆？！！！！
- 对不起但是真的很好笑

**⑥ 反差/对比（3.6%）**
两个不相容的东西并置，冲突感来自落差。

- 22 年前 vs 现在
- 我妈以为的 vs 实际的

**⑦ 第一人称家事（2.8%）**
"我妈/我婆婆/我老公/我同事"开头，用具体人物制造窥私欲。注意：整体只有 13.3% 的标题含"我"，说明**不是主流打法，但在情感/家庭赛道极有效**。

### 1.3 可直接套的 12 个句式

1. **反常陈述**：`[主体] + [做了件不合常理的事] + [结果]`
   → 女子用虹吸法排积水
2. **物件 + 用途错位**：`把 [A] 挂在 [B] 上，[结果]`
   → 奶奶把钥匙挂在狗脖子上
3. **悬念 + 括号补丁**：`[现象] 怎么办（+进度/身份）`
   → 隔壁好像臭了怎么办（后续已更新）
4. **反常识提问**：`为什么 [越 X] 的人 [越 Y]？`
   → 为什么越精神不正常的人反而越有性张力呢
5. **断言式观察**：`[某个下意识反应] 是骗不了人的`
   → 下意识的肢体接触排斥是骗不了人的
6. **数字 + 限定**：`[N] 款/个 [品类]，[最想解决的痛点]`
   → 3 款平价连衣裙，显瘦不显肚子
7. **时间限定 + 稀缺**：`[季节/节点] 不可少的 [品类]（上/下期）`
8. **对比并置**：`[预期] vs [实际]`
9. **自嘲认领**：`我妈也算是吃上 [X] 的苦了`
10. **道歉式开场**：`对不起，但是真的 [情绪词]`
11. **人群点名**：`[身份] 都给我 [动作]`（慎用，容易硬广感）
12. **一句结论 + 反转**：`我以为 [A]，结果 [B]`

### 1.4 三个反例（来自"低赞高相似"的对照组）

- ❌ **《分享一下我的日常穿搭》** —— 没有信息，没有冲突，没有对象。
- ❌ **《关于减肥这件事我的一些心得体会》** —— 12 个字里 8 个字是废话，"关于…这件事"是书面语肿瘤。
- ❌ **《姐妹们！这个真的绝绝子！！！》** —— 三年前有效，现在等于没写；样本里感叹号只有 13.3%，堆感叹号不是主流。

改法：把"我在说什么"换成"发生了什么"。"分享一下我的日常穿搭" → "158 穿这条阔腿裤，同事问我是不是长高了"。

## 2. 封面：五种基本盘，选一种做到位

看了 100 张热门封面（4 列 × 12 格联系表），可以明确分成五族。**没有"好看"这回事，只有"这一族有没有做到位"**。

### 族 1：视频截帧 + 大字花字（视频号主力）

- 直接取视频里信息量最大的一帧，人物脸或动作居中偏上。
- 文字压在**画面下方 1/3**，黄色或白色**粗体 + 2–4px 黑描边**，一句话，10–16 字，不超过两行。
- 文字说的是"这句话本身好笑/有信息"，不是标题的重复。
- 样本里出现频率最高的一族。要点：**字要大**。手机信息流里封面宽度约 170px，字号小于 40px（按 1080 宽算）就等于没写。

### 族 2：纯色底 + 文字提问卡（观点/情感/知识号）

- 米白/浅黄/浅灰底 + 上方一个小引号 + 2–3 行问句 + 底部一个手绘小人/简笔图标。
- 字号极大，占画面 40% 以上，行距松。
- 优点：在满屏实拍里极显眼；缺点：只能承载"一句话观点"，不适合展示产品。
- 样本里这类常出现在"为什么…""你们会不会…"型内容。

### 族 3：实拍 + 轻标注（穿搭/美食/家居/探店）

- 主体占画面 70%，背景干净（白墙、街景、餐桌俯拍）。
- 标注是**小字 + 引线/圈选**，不是大字报：`这件 79 / 显瘦 / 上期那件`。
- 穿搭常用**拼图**：一张封面里 4 格或 9 格，展示同一套的正面/侧面/细节，或 3 套并列。
- 美食常用**人 + 食物同框**，手写体标注菜名/价格/地点。
- 要点：**这类封面的竞争力在"主体是否清楚"**，糊、暗、杂物多 = 直接划走。

### 族 4：手机截图（聊天记录/订单/物流/评论）

- 真实截图，保留状态栏（时间、电量、信号）—— 这是"真实感"的关键道具。
- 只截关键 3–5 行，其余打码或裁掉。
- 常配一行手写体旁白指出笑点。
- 样本里这类多用于"我妈给我发…""外卖小哥…""面试 HR 回我…"。

### 族 5：拼图/多图对比（测评、合集、改造前后）

- 2 格（before/after）或 3–4 格（款式并列），每格下方一个短标签。
- 要点：**格与格之间要有可比性**（同角度、同光线、同背景），否则读者读不出差异。

### 通用版式规范

| 项 | 建议 |
|---|---|
| 尺寸 | **1080 × 1440（3:4 竖版）**，信息流里 3:4 占比最大 |
| 安全区 | 上下各留 8%，避免被标题栏/按钮压住 |
| 字号 | 主文案 ≥ 90px（1080 宽），副文案 ≥ 45px |
| 描边 | 白字配黑边 4px，或黄字配黑边 3px |
| 配色 | 最多 3 色；黄/红/白在信息流里对比最强 |
| 人物 | 有脸 > 有手 > 只有物；人脸朝画面内，别朝外 |
| 文字量 | 一行 ≤ 12 字，总共 ≤ 2 行 |

## 3. 正文：91 字是常态，但两个极端都能活

### 3.1 数据画像（359 篇）

| 指标 | 数值 |
|---|---|
| 长度中位数 | **91 字**（p25 = 49，p75 = 161，p90 = 316，均值 141） |
| 段落数中位 | **1** |
| 首行长度中位 | **40 字** |
| 含换行 | 41.4% |
| 含 emoji | 13.8% |
| 含内联 `#话题#` | **90.3%** |
| 用 `1. 2. 3.` 数字列表 | **1%** |
| 用 `▶ / · / -` 分点 | 1% |
| 有"二编/后续/更新" | 3% |
| 含 @ | 4.4% |
| 附外链 | 0% |

**正文长度与热度：**

| 字数 | 篇数 | 中位赞 |
|---|---|---|
| 0–50 | 93 | 6286 |
| 50–100 | 105 | 3458 |
| 100–200 | 99 | 3114 |
| 200–400 | 41 | 122 |
| 400+ | 24 | **6490** |

这不是"越短越好"，而是**两头都能爆、中间最平庸**：
- **≤50 字的"一句流"**：靠封面和标题已经说完了，正文只是补一句情绪或地点，适合视频/新闻/搞笑。
- **400+ 字的长文**：情感叙事、亲身经历、深度测评，靠"我看完了"换收藏和长评论。
- **200–400 字区间最尴尬**：想讲清楚又讲不透，读者既没被逗笑也没被说服。样本里这一档中位赞只有 122（含较多垂类小号，需谨慎解读，但趋势清楚）。

**结论：要么 50 字以内，要么 400 字以上，别停在 200–300 字。**

### 3.2 五种结构模板

**模板 A：一句流（≤50 字，视频/新闻/搞笑）**
```
[一句现场感的话，补标题没说的细节]
[地点/时间/人物关系，一行]
#话题1 #话题2 #话题3
```
样本例：标题"女子用虹吸法排积水"，正文一行交代小区和物业反应。

**模板 B：三行说明（50–120 字，图文/穿搭/美食）**
```
第一行：结论/价格/地点（最有用的一句）
第二行：2–3 个具体细节（材质、尺码、口味、耗时）
第三行：一句人话（我为什么发它）
#话题 ×5–8
```

**模板 C：分点清单（120–300 字，教程/攻略/测评）**
不用 markdown 的 `1.`，用 **emoji 或空行分段**。样本里只有 1% 用数字列表——小红书用户不读编号，读"一块一块的短段"。
```
📌 先说结论：xxx
·
① 具体做法（一句一行）
② 具体做法
③ 具体做法
·
⚠️ 一个坑：xxx
#话题 ×6
```

**模板 D：长文叙事（400–800 字，情感/经历/复盘）**
```
开头：直接进场景，不铺垫（"那天我在医院走廊坐了四个小时"）
中段：3–5 个短段落，每段 2–4 行，一段一个动作或一句对话
转折：一个具体到细节的瞬间（数字、天气、原话）
结尾：不总结、不喊口号，落在一个动作或一句自嘲上
二编：（可选）回应评论区质疑/补充后续
#话题 ×3–5
```

**模板 E：图文配图说明（图片为主，正文是图注）**
```
⬆️ 图 1：xxx
⬆️ 图 2：xxx
⬇️ 图 3：xxx
```
用 `⬆️⬇️` 指向具体图，是图文笔记里最省力也最像真人的写法。

### 3.3 标签策略

- **数量：中位 5 个，均值 5.1。** 分档看热度：

| 标签数 | 篇数 | 中位赞 |
|---|---|---|
| 0–1 | 35 | 5946 |
| 1–3 | 62 | 1080 |
| 3–5 | 82 | 3268 |
| **5–8** | 75 | **11000** |
| 8+ | 108 | 3114 |

**5–8 个最优，1–3 个最差。** 少于 3 个等于放弃分类流量；多于 8 个会稀释主题（样本里 9% 完全不带标签，多为大号或纯情绪内容，不建议模仿）。

- **结构：1 个大词 + 2–3 个中词 + 2–3 个长尾词 + 1 个自造词。**
  - 大词：`#穿搭` `#美食`（进大池子，竞争激烈）
  - 中词：`#小个子穿搭` `#打工人午餐`
  - 长尾：`#158微胖穿搭` `#10块钱吃饱`
  - 自造词：`#我妈的迷惑行为`（形成系列感，方便别人点进你的主页）
- **位置：写在正文末尾，用 `#话题#` 内联形式**（90.3% 的样本这样写）。小红书会自动把 `#xx#` 变成话题标签，比在发布页单独加更自然。
- 唯一 1% 提到 `@薯队长/@穿搭薯` 等官方号——**不是必需动作**，别把它当玄学。

### 3.4 排版细节（这几条比文采重要）

1. **首行 40 字以内说完最有用的一句。** 展开前只显示 2 行，首行决定要不要点"展开"。
2. **一段不超过 4 行**，行与行之间空一行。样本里 41.4% 含换行，纯一大段的几乎是搬运内容。
3. **emoji 用在段落开头当分隔符**（📌 ⚠️ ✅），不要句句结尾都加。样本正文含 emoji 只有 13.8%——**小红书不是 emoji 重灾区，别堆**。
4. **口语词替换书面词**：`非常 → 真的`、`因此 → 所以`、`进行 → 做`、`较为 → 有点`、`建议您 → 你可以`。
5. **留一个"可评论的口子"**：结尾抛一个具体问题（"你们那儿这个多少钱？"），或在正文里故意留一个可被纠正的小错（样本里大量高赞评论是"纠错"，说明这是有效钩子——但别拿事实错误赌）。
6. **"二编"是加分项**：样本 3% 有后续更新，这类笔记常因评论区争议二次起飞。写法：`二编：没想到这么多人看，补充一下…`
7. **不要放外链**（样本 0%），不要写"点赞关注"（会限流）。

### 3.5 什么时候发

⚠️ 样本里发布时间集中在 8–12 点（受抓取时段影响，**不能用来推断最佳发布时间**）。给的是经验值，不是数据结论：

- 通勤 7:30–9:00、午休 12:00–13:30、睡前 21:00–23:00 是三个流量高峰。
- 垂类错峰：职场类工作日中午，穿搭类周五晚/周末上午，美食类 11:00 和 17:00 前（饭点前决策）。
- 稳定比精准重要：固定时段发，粉丝会形成预期。

## 4. 评论区：最靠前的 5 条，才是别人真正看到的"你的内容"

| 类型 | 占比 |

| 长评论（≥80 字） | 8.6% |
| 补充信息/科普 | 6.9% |
| 玩梗/接梗 | 7.8% |
| 共鸣/自我代入 | 4.8% |
| 夸赞/纯情绪 | 4.2% |

另外还有 **50.1%** 未被规则命中、归在"其它"，翻看语料后主要是**"针对内容里某个具体细节的观察/调侃"**——这是绝对数量最大的一类，也是最能体现"像真人"的一类。

### 4.2 排序逻辑（推断，非官方）

从前 5 条的构成反推，小红书评论区的综合排序大致加权：**点赞 > 回复数 > 是否被作者点赞/回复 > 新鲜度 > 长度（适度加分）**。所以：

- **短而准的评论能上前排**（"标本的意思查一下"7 字，前排）。
- **被作者回复过的评论会被顶上来**——这是作者最好用的运营杠杆。
- **@好友的评论会被折叠到二级**，所以前 5 条里 @ 只有 0.3%（不是没人 @，是 @ 不进前排）。

### 4.3 前排九种发言（附真实语料）

**① 抓一个具体细节，放大成笑点**（最高频，也最"真人"）
不评论整体，只咬住画面/文字里的一个点。

> 这个鞋子感觉是羊脚穿的啊
> 乍一看以为是梁朝伟
> 你没有用公鸡蛋

**② 第一人称补充自己的经历**（26.8% 的评论含"我"）
把自己放进同一个场景，给一个**具体的数字或限定**。

> 我们钟点工包月的，不来也要付钱
> 哈哈好喜欢但是已经40了不好意思穿
> 我都是把钱存在麻将🀄️上，想剁手了，但是又想把它赢回来

**③ 共鸣式接话**（把对方的感受说得更准）
> 尤其耍手机，不知不觉几个小时就没了
> 像我这样不思进取的，应该能活很久吧

**④ 提问/求助**（18.1%）
问得越具体越容易被回。

> 来个人说说这个好吃嘛
> 其实我想问女生擦了口红，这样亲口红会不会抹到乱七八糟（真诚提问）
> 不懂就问，如果楼上有💩正好冲下来，而你又刚好这样做，会不会……

**⑤ 纠错/科普/换算**（6.9%）
给出一个别人不知道的事实或算一笔账，这是最容易拿赞的类型。

> 标本的意思查一下
> 一天10块，一年也才6500
> 90年代的12.5万美元不少了

**⑥ 站队/审判**（8.7%）
明确表态，站在某一方，语气可以冲但不能人身攻击。

> 确实是需要一个敢说的人，哈哈
> 衣服好是好 还要看身材和脸呀[doge]

**⑦ 玩梗/谐音/接龙**（7.8%）
> 看成 南朝梦遗
> 识别中
> 一路走好，38 如果在 pdd 算高寿了

**⑧ 短附和/纯情绪**（12.7% + 4.2%）
只有在自己已经是熟号、或者句子足够妙时才有效；陌生人发"绝了"基本等于没发。

> 这个是最在理的！！！
> 刚出炉
> 好好看

**⑨ 替人配内心戏/续写**
> 内心：又整这出哈哈哈哈哈哈哈哈哈
> 可能觉得她爱他，希望她忘了他，去找一个更好的人

### 4.4 怎么写出"像真人"的评论：五步法

1. **先找那个"只有看过的人才知道"的细节**（画面角落、文案里的数字、背景里的物件），从它切入。
2. **把评论写成一个动作或一句原话**，不要写成评价。"我妈当场把碗放下了" > "太好笑了"。
3. **加一个限定**：年龄、城市、职业、价格、时间。"我 32 岁第一次穿吊带" 比 "我也想穿" 有力十倍。
4. **长度控制在 15–40 字**（中位 17 字），一句话能说完就别两句。要长就长到 80 字以上（长评是独立物种，8.9% 但拿赞率高）。
5. **检查有没有"AI 味"**：
   - ❌ 三段式总结（"首先…其次…最后…"）
   - ❌ 形容词堆叠（"真的非常超级无敌好看"）
   - ❌ 万能夸（"博主好棒，学到了"）
   - ❌ 书面语（"个人认为此举欠妥"）
   - ❌ 句末句号过多（真人评论很少用句号收尾）
   - ✅ 有错别字、有语气词（啊/呢/吧/诶/哈）、有省略号、有不完整句

### 4.5 作者怎么运营评论区

样本里 9% 的前 5 条是作者，且第 1 条被作者占据的有 23/119。头部作者的做法固定为四种：

1. **开场自报家门**（相亲/职场/情感类最常见）
   > 好多人啊，简单自我介绍一下，本人张铁嘴，长期相亲，目前成功率约等于刮刮乐中奖……
2. **置顶解释/控评**
   > 大过节的图个开心，不喜欢他们的，不好的言论我会删！不要破坏大家的心情[笑哭R]
3. **顺着评论区玩**
   > 好滴呢，看到大家都说是老鼠我就放心了
4. **认真答问**（把高赞提问逐个回掉，回复会把该评论顶到前排）
   > 我一般都是喜欢哪个选哪个

**动作清单：**
- 发布后 30 分钟内守在评论区，回前 10 条，优先回"提问"和"纠错"。
- 自己发一条"补充信息"评论并置顶（成本最低的二次信息位）。
- 遇到恶评：删，不吵。样本里作者公开表态"不好的言论我会删"是常见且被接受的做法。
- 不要复制粘贴同一句回复，会被识别为机器行为。

### 4.6 雷区

- 广告导流（"私我""看我主页""加V"）→ 限流或删评。
- 拉踩品牌/地域/性别对立 → 短期有量，长期账号标签变差。
- 无意义刷屏（"1""沙发""来了"）→ 不进前排，纯浪费。
- 评论区吵架 → 会把笔记推向"争议流量"，完播和收藏双降。
- 复制别人的高赞评论 → 平台有查重，且用户会点踩。

### 5.3 正文骨架 5 条

- **一句流**：现场一句话 + 地点/时间 + 3–5 个标签。
- **三行说明**：结论（价格/地点）→ 2–3 个细节 → 一句人话 + 5–8 个标签。
- **分点清单**：结论 → emoji 分段 3–5 条 → 一个坑 → 6 个标签。
- **长文叙事**：直接进场景 → 3–5 个短段 → 一个细节转折 → 落在动作上 →（二编）+ 3–5 个标签。
- **图注式**：⬆️ 图1 → ⬆️ 图2 → ⬇️ 图3 + 5 个标签。

## 附录：样本与方法

**样本**
- 425 篇笔记（`data/notes.jsonl`），其中 362 篇含正文，用于标题/正文/标签统计。
- 类型：图文 188 / 视频 174（视频均赞 22328，图文 8904）。
- 时间跨度：2023-02-25 ~ 2026-10-06。
- 133 篇笔记的前 5 条一级评论，共 663 条（`data/comments.jsonl`）。
- 题材分类覆盖 359 篇（其余为纯图片或无文字视频）。

**题材分布（规则分类，每篇取首个命中）**
其它 130 / 穿搭美妆 57 / 美食 47 / 影视综艺娱乐 42 / 健身健康 15 / 宠物 13 / 数码科技 13 / 职场学习 11 / 家居生活 8 / 情感关系 8 / 社会新闻 6 / 旅行户外 6 / 游戏二次元 3。
"其它"里主要是搞笑段子、萌娃、社会观察和无法用关键词归类的混合内容。

**样本多样性（对应"降低标签重合"这一要求）**
- 共 **1670 个唯一标签**，最热标签的覆盖率也只有 **1.9%**（"早春晴朗""万万没想到""搞笑"各命中 7 篇）。
- 频次最高的 50 个标签只覆盖 **29%** 的笔记，剩下 71% 的笔记带的都是长尾标签。
- 随机抽 2000 对笔记，平均标签 **Jaccard 相似度 0.004**，几乎不重叠。
- 题材横跨 13 个类目，图文 188 / 视频 174 基本对半。

也就是说，这里归纳的不是"某一类爆款"，而是各类内容共通的写法。

**抓取方式**
1. `www.xiaohongshu.com/explore` 与推荐流的 SSR `window.__INITIAL_STATE__`（需同时带 `user-agent` 与 `accept-encoding: gzip, deflate, br`，否则返回空壳）。
2. 单篇正文：`/explore/<id>?xsec_token=...`，正文在 `noteDetailMap[id].note.desc`。
3. 评论：SSR 里 `comments` 恒为空、签名接口返回 406，改用无头 Edge + CDP 真浏览器渲染，取 `.comment-item` 前 5 条。

**必须说明的偏差**
1. **样本偏推荐流**（频道页免登录被登录弹窗遮挡，仅拿到少量穿搭/美食），因此"泛热门"的代表性较好，"垂类内部规律"的代表性较弱。
2. **评论点赞数不可用**：网页端把点赞压成 `10+` / `1千+` / `赞`，所以本指南不做"点赞越高=越优质"的强度结论，只讨论"什么内容能进前 5 条"。
3. **含 emoji 比例偏低**：小红书评论里的 emoji 是图片，抓取后只剩 `[笑哭R]` 这类码（9.4%），真实比例应更高。
4. **视频 `[时刻]` 章节目录只统计到 0.3%**，但这是有用写法（适合教程/长视频），样本少不代表不该用。
5. 标题/正文长度与热度的关系是**相关性**，混淆因素很多（垂类、账号体量、发布时间），请当作倾向而非定律。
