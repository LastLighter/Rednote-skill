# 封面设计

封面只干一件事：**在 0.5 秒内让人点进来。**

---

## 一、最常见的死法：画面太空

```
错误：浅色纯背景 + 两行大字 + 一个小图标
结果：刷到像 PPT 封面，直接划走
```

**规则：画面必须被填满，四边铺满，不允许出现大面积纯色背景。**

填满不等于堆砌。有效的做法是"大字 + 人物 + 道具 + 散落小元素"四层结构：

| 层 | 内容 | 占比 |
| --- | --- | --- |
| 文字层 | 2 行大字 + 1 个色块标签 | 上 1/3 |
| 人物层 | 人设 / 当事人形象，半身 | 40–45% |
| 道具层 | 核心物件（书本、显示器、手机） | 与人物互动 |
| 散点层 | 碎玻璃、小色块、单字母、图标 | 铺满剩余区域 |

散点层是拉开"廉价"和"高级"的关键——但必须是**纯图形**，一旦出现乱码英文，质感立刻崩。

### 视觉张力优先：人物面部大特写

封面的第一任务是**在信息流里把人拽住**，所以优先用最大胆的那一种构图：**一张脸占满画面**。

- 脸占画面 70% 以上，头顶和两侧可以出画（被边缘裁掉一点更有冲击力）
- 只露眼睛到下巴，身体不出现
- 表情夸张到变形：震惊到瞳孔缩成小点、嘴巴张成"O"、汗珠、红晕；或者愤怒、不可思议、破防
- 大字压在脸上，和眼镜/头发形成前后层次
- 背景依然要被散点填满，不留大片纯色

**先问"这张脸在说什么"，再问"大字写什么"。** 表情是情绪，大字是结论，两者一起才有点击。

### 原帧往后退一格

原帖里的对比画面依然是硬证据，但它更适合放在**第二张**：封面负责抢注意力，第二张负责证明"这是真的"。

只有一种情况原帧上封面：原帧本身就是整件事的爆点，而且画面本身足够炸（比如离谱的界面、荒诞的报错）。即便如此，也要给人物或大字留出位置，别把封面做成一张截图。

---

## 二、双钩子：封面 ≠ 标题

| | 打什么 | 字数 |
| --- | --- | --- |
| 标题 | 情绪 / 站队 / 信息缺口 | 15 字上下 |
| 封面 | 一句人话 + 情绪判断 | 4–8 字 |

两者指向同一个点，但**表述必须不同**。

| 场景 | 标题 | 封面大字 |
| --- | --- | --- |
| ✅ | 我宣布，AI视频新神是Opus5.5 | 差了一条街 |
| ✅ | 高市早苗官网，被PHP干停了 | 出版社叫 PHP |
| ❌ | 高市早苗官网，被PHP干停了 | 高市早苗官网，被PHP干停了 |

封面把标题抄一遍，等于一个入口只用了半次。

### 大字要像人说的话

好用的封面大字，是**一个人看完之后的判断**，不是一份报告的小标题。

| 像人话 | 像通稿 |
| --- | --- |
| 差了一条街 | 差距肉眼可见 |
| 贵得有理 | 性价比分析 |
| 一个能玩，一个只能看 | 生成质量对比 |

### 两个模型/两个对象对比时，必须标清谁是谁

图里出现两个屏幕、两种结果，**每个画面旁写清归属**（模型名、品牌名、型号），用两个不同颜色的色块区分。读者看完封面就要知道"哪边是谁"，不能只靠第二张图解释。

### 别把类别写错

大字里的比喻必须对得上帖子在讲什么：一段 AI 生成的像素风视频，是"视频生成"的对比，不是"它俩做了两个游戏"。比喻一旦错位，正文就得先花半句去圆，封面也经不起追问。

## 三、文字层级

三档足够，不要更多：

```
第一档  巨大的黑色超粗黑体      字号 ≈ 画面宽的 1/4
第二档  同字体，约 70% 大小     承接第一档
第三档  高饱和色块 + 黑色粗体    标签式，5 字左右
```

字体：**方正硬朗的中文黑体**（思源黑体 Heavy / 站酷酷黑 / 优设标题黑一类）。
不要细体，不要圆体，不要书法体，不要渐变字。

色块标签是小红书封面的标志性语言：亮黄 / 亮绿 / 亮红 + 黑字，像警示牌。

---

## 四、人物放哪

| 方案 | 适用 |
| --- | --- |
| 人物居中，大字压在其后 | 冲击力最强 |
| 人物偏一侧，另一侧全给标题 | 版面大气，信息清楚 |
| 人物从边缘探身进来 | 有"围观"感，适合吐槽类 |
| 人物只露手/半张脸 | 适合产品、物件为主的内容 |

同一组图里**人物位置尽量统一**（都在右下，或都在左下），刷起来像系列，而不是散装。

---

## 五、账号人设图

有固定人设（卡通形象、手绘头像）的账号，**一定要把人设放进封面**。

- 提升账号识别度，达到"看图识号"
- 让"你"成为内容的一部分，而不只是一个搬运工
- 卡通人设还规避了真人肖像的种种麻烦

用法：作为**参考图1**传给图像模型，并在提示词里写明"保持发型、眼镜、服装与画风一致"。

---

## 六、真实人物

内容涉及公众人物时：

- **用已知人物的本名**，不要把名字换成"某国首相"这类泛称，泛化会把情绪抽干
- 配图优先用**扁平卡通/插画形象**。一来与卡通人设统一，二来不会有"像不像"的尴尬
- 若需要更强辨识度，用当事人公开照片作为参考图，而不是纯文字描述——纯文字描述会让模型凭空编一张脸

---

## 七、封面 CHECKLIST

- [ ] 四边铺满，没有大面积纯色背景
- [ ] 有一个占画面 70% 的大特写或强视觉主体
- [ ] 表情/动作夸张，情绪一眼可读
- [ ] 大字 2 行以内，黑色超粗黑体
- [ ] 有一个亮色块标签，≤ 6 字
- [ ] 封面大字与标题不重复
- [ ] 大字像人说的话，不是通稿小标题
- [ ] 两个对象对比时，每个画面都标了归属
- [ ] 人物、道具、散点四层都有
- [ ] 有证据画面时，用的是原帧而不是重画
- [ ] 除指定文字外，没有任何其他文字（原帧自带的除外）
- [ ] 关键元素距四边 ≥ 5%
- [ ] 中文逐字核对，无错字
